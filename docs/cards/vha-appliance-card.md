## 目标

程序类家电：有程序名、剩余时间、阶段、启动和电源。不是一枚简单开关。简单开关用 [设备卡](vha-device-card.md)。

替换：

- 盈松小窝「生活阳台」的 `custom:tebo-washer-final-card`
- 顶栏徽章和移动设备分区里的剩余时间只是数据来源，徽章本身仍用 HA 原生，不做成插件。剩余时间实体是 `sensor.mibx5_cn_928578973_f531_left_time_p_2_10`

卡片不要绑死某一厂商。tebo 只是现在的被替换对象。洗衣机、烘干机、洗碗机、扫地机都用同一套可配置实体。

## 适配实体

用「主状态 + 若干可选实体」描述一台家电，而不是识别品牌：

- 主状态实体：程序或阶段。可以是 `sensor`、`select`，或集成提供的洗衣机类实体
- `time_entity`：剩余时间传感器
- `program_entity`：程序名。不填则从主实体状态或属性读
- `progress_entity`：0–100 的进度。不填则用剩余时间估算；都没有则不显示进度条
- `power_entity`：电源开关
- `start_entity`：启动 / 暂停。`button`、`script`、`switch` 或 `input_boolean`

扫地机如果只有开始和回充，也可以用这张卡：`start_entity` 开始，电源或第二个动作用 `power_entity`。不要为此改去设备卡，除非它只是一个开关、没有程序和时间。

## 功能设计

- 显示程序名、大号剩余时间、阶段文案、进度条。
- 有 `start_entity` 时显示主操作按钮：启动或暂停（由该实体状态决定文案）。
- 有 `power_entity` 时显示电源开关，样式与设备卡相同。
- 点击信息区（图、程序名、时间）打开主实体的 more-info。
- 没有对应实体的块直接不渲染，不留空按钮。

剩余时间格式：传感器若已是「1 小时 20 分」就原样显示；若是秒或分钟数值，格式化成 `H:MM` 或 `M 分钟`。

## 交互入口

| 操作 | 结果 |
| --- | --- |
| 点击主按钮 | `button.press`、`script.turn_on`，或对 switch / input_boolean `turn_on` / `turn_off`。运行中且实体可关时显示「暂停」 |
| 点击电源 | `power_entity` 的 `turn_on` / `turn_off` |
| 点击程序名、时间或设备图 | 主实体 more-info |
| 只有传感器、没有按钮实体 | 纯展示，无主按钮 |

不在卡片里编辑洗衣程序清单。改程序仍走 more-info 或 HA 自己的 select。若 `program_entity` 是 `select`，可以在后续用胶囊改程序，第一版只展示，避免把气候卡的模式交互复制错。

## 前端界面需求

- 白底、16px 圆角。
- 左：设备图或线性图标。右或下：程序名 14px 加粗，阶段 12px 灰色。
- 剩余时间是卡片里最大的数字，约 28–32px。
- 进度条细、圆角，已完成部分 `#1a1a1a`，剩余 `#e4e6ea`。
- 主操作是深色圆角按钮「启动」或「暂停」，不是开关。电源仍用 36×20 开关，放在按钮右侧。
- 无图时用洗衣机/家电线框图标，不引用 tebo 的图片资源。
- 建议网格：6 列、3 行。

## 配置项

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `entity` | 是 | 主状态实体 |
| `name` | 否 | 设备名，默认友好名称 |
| `image` | 否 | 设备图 |
| `time_entity` | 否 | 剩余时间 |
| `program_entity` | 否 | 程序名 |
| `progress_entity` | 否 | 进度 0–100 |
| `power_entity` | 否 | 电源 |
| `start_entity` | 否 | 启动或暂停 |

示例：

```yaml
type: custom:vha-appliance-card
entity: sensor.mibx5_cn_928578973_f531_left_time_p_2_10
name: 洗衣机
time_entity: sensor.mibx5_cn_928578973_f531_left_time_p_2_10
```

生活阳台现卡若还有程序、电源实体，实施时把它们填进对应字段。规划不猜测 tebo 卡内部的私有实体；接上后以 HA 里实际实体为准。

## 验收要点

1. 只配剩余时间时，卡片显示大号时间，没有假的启动按钮。
2. 配上 `start_entity` 和 `power_entity` 后，启动和电源各调用各的服务。
3. 进度条在有 `progress_entity` 时按百分比；没有则隐藏或仅在能从时间估算时显示，不出现永远 0% 的条。
4. 点击名称或时间打开 more-info，点击按钮不会打开。
5. 换一套烘干机或扫地机实体（改配置、不改卡片类型）仍能显示程序和时间。
6. 顶栏洗衣机徽章保持 HA 原生，本卡不注册徽章。
7. 视觉与设备卡的圆角、字体、开关一致。
