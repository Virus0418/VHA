# 气候卡 `custom:vha-climate-card`

工单：[#3](https://github.com/Virus0418/VHA/issues/3)。目标列：待审查。尚未在真实 Home Assistant 上验收，不能标「卡片通过」。

视觉以 [设计规范 1.0](../design-spec-1.0.md) 的气候卡为准。制热和制冷是同一张卡的模式变体，不是两张卡。宽度跟着 Home Assistant 的栏走，不把设计稿上的 448 写死。

## 本轮做了什么

- 标题、溢出菜单、圆形电源。点标题或主数值区打开更多信息；电源、模式芯片和风速滑杆自己处理点击。
- 主数值是当前温度，保留一位小数，单位前有空格，例如 `22.5 °`。
- 副文案按当前模式和目标温度生成。制冷是「制冷至 20 °」，制热是「制热至 24 °」，关闭是「已关闭」。不会套用组件稿里默认的 Heating to 24 °。
- 模式芯片来自实体的 `hvac_modes`，文案用中文（制热、制冷、自动、送风、除湿、冷热）。`off` 不做成芯片，由电源负责。选中芯片是深色底白字，对比强于稿面上几乎同色的白底细边。
- 实体有 `fan_modes` 且未关闭 `show_fan` 时，显示横向风速滑杆。百分比写成 `60 %`。松手后吸附到最近的风速模式并调用 `climate.set_fan_mode`。
- 底色随模式变化：制热 `#FFE7C4 → #FFF1DC → #F7EEE4`，制冷 `#DCEAFB → #E7F1EE → #E4EEF7`，关闭、不可用、未知用中性底 `#F0EFF2`。
- 关闭时芯片和风速禁用，电源仍可打开。不可用显示「不可用」，未知显示「未知」，电源一并禁用。
- 域不是 `climate`、实体不存在、服务失败时不白屏。服务失败在卡上留一句短错误。

## 本轮不做

工单里的圆环调温、型号行、摆风、耗电块不在这张卡上。目标温度只显示在副文案里，修改请打开更多信息。这些仍留在工单里，不算已经完成。

## 配置项

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `entity` | 是 | `climate` 实体 |
| `name` | 否 | 标题。留空用友好名称 |
| `show_fan` | 否 | 是否显示风速滑杆。省略为显示；实体没有 `fan_modes` 时本来就不画 |

```yaml
type: custom:vha-climate-card
entity: climate.living_room
name: 客厅
show_fan: true
```

编辑器在 Home Assistant 里用 `ha-form`，标签为中文。窄栏时芯片换行，标题可以折成两行。
