# 气候卡 `custom:vha-climate-card`

工单：[#3](https://github.com/Virus0418/VHA/issues/3)。目标列：待审查。真实 Home Assistant 上曾验收失败（关闭态点不了，版式和设计稿差太远）。本轮修了关闭态操作和 `hass` 重绘，**还要等用户更新插件后再测，不能标「卡片通过」**。

视觉以 [设计规范 1.0](../design-spec-1.0.md) 的气候卡为准。制热和制冷是同一张卡的模式变体，不是两张卡。宽度跟着 Home Assistant 的栏走，不把设计稿上的 448 或 580 写进 CSS。

## 本轮做了什么

- 标题、溢出菜单、圆形电源。点标题或主数值区打开更多信息（`hass-more-info`，`detail: { entityId }`，冒泡且可穿过 shadow）。电源、模式芯片和风速滑杆自己处理点击。
- 主数值是当前温度，保留一位小数，单位前有空格，例如 `22.5 °`。
- 副文案按当前模式和目标温度生成。制冷是「制冷至 20 °」，制热是「制热至 24 °」，关闭是「已关闭」。不会套用组件稿里默认的 Heating to 24 °。
- 模式芯片来自实体的 `hvac_modes`，文案用中文（制热、制冷、自动、送风、除湿、冷热）。`off` 不做成芯片，由电源负责。选中芯片是深色底白字。关闭时没有选中芯片。
- 实体有 `fan_modes` 且未关闭 `show_fan` 时，显示横向风速滑杆。百分比写成 `60 %`。松手后吸附到最近的风速模式并调用 `climate.set_fan_mode`。
- 底色随模式变化：制热 `#FFE7C4 → #FFF1DC → #F7EEE4`，制冷 `#DCEAFB → #E7F1EE → #E4EEF7`，关闭、不可用、未知用中性底 `#F0EFF2`。这些颜色写在 `--ha-card-background` 上，避免 Home Assistant 的 `ha-card` 默认底色和边框盖住卡片。深色主题下卡片仍是浅底深字。
- 关闭时布局不变：标题、溢出、电源、caption、主温度、副文案、芯片、可选风速。芯片与开启时的默认芯片一样，白底深字、有阴影，不因为 `disabled` 变淡。点击某个模式会调用 `climate.set_hvac_mode`（通常会开机），不会先报「已关闭」。
- 电源开机先 `climate.turn_on`。集成不支持或调用失败时，改切到这张卡上一次看到的模式；没有上一次模式，就用 `hvac_modes` 里除 `off` 外的第一个。关机仍用 `turn_off`，失败再回退 `set_hvac_mode: off`（模式列表里有 `off` 时）。
- 只有 `unavailable`、`unknown` 或实体不存在时禁用写入。不可用显示「不可用」，未知显示「未知」。
- 域不是 `climate`、实体不存在、服务失败时不白屏。服务失败在卡上留一句短中文错误。
- Home Assistant 会很频繁地替换 `hass`。视图数据和错误文案没变时，气候、设备、传感器、媒体四张卡都跳过 `innerHTML` 重绘，避免把点在按钮、芯片、电源或滑杆上的手势拆掉。拖动滑杆时本来就不重绘。
- 标题最多两行，在空格处换行，超出省略。长友好名不会从汉字中间拆成很多行。用户仍可以在「名称」里写短标题。
- `getGridOptions` 至少 4 列。有风速时约 6×8，没有风速时约 6×7，按 448×580 的比例估，不再用 6×5 把内容压扁。窄栏只收垂直留白，不把设计稿高度写死。

## 本轮不做

工单里的圆环调温、型号行、摆风、耗电块不在这张卡上。目标温度只显示在副文案里，修改请打开更多信息。这些仍留在工单里，不算已经完成。

## 配置项

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `entity` | 是 | `climate` 实体 |
| `name` | 否 | 标题。留空用友好名称 |
| `show_fan` | 否 | 是否显示风速滑杆。省略为显示；实体没有 `fan_modes` 时本来就不画 |

```yaml
type: custom:vha-climate-card
entity: climate.living_room
name: 客厅
show_fan: true
```

编辑器在 Home Assistant 里用 `ha-form`，标签为中文。窄栏时芯片换行，标题最多两行。

在「添加卡片」里，会从当前家里的 `climate` 里挑一台做示意，优先有模式、并且不是不可用或未知的那台。这样选卡面板能看到标题、温度和芯片，而不是「请选择一个实体」。家里没有气候实体时才回到这句空态。示意不会调用服务。
