# VHA 卡片审核与发布标准

每张卡片在合并实现、打版本、进入 Home Assistant 实机测试前，都按本文审核。

- 达不到「卡片通过」：不合并该卡的实现。
- 达不到「试用版」：不安装到正在使用的 Home Assistant。
- 不必等九张卡都做完，才做第一次实机测试。

视觉与排版以 [设计规范 1.0](design-spec-1.0.md) 为准。规划文档、卡片文档、代码必须与该规范一致，不以旧的字号、圆角或字体约定为准。

---

## 1. 一张卡要过的四道关

| 关卡 | 过关标准（一句话） |
| --- | --- |
| 设计 | 信息结构清楚，视觉符合规范 1.0，模块可开关，窄宽度下也不乱。 |
| 配置 | 能在「添加卡片」里找到，可视化编辑器和 YAML 一致，字段稳定。 |
| 行为 | 对真实实体显示和操作正确，异常状态安全，失败可见，不拖垮页面。 |
| 安装 | 能随插件安装和升级，旧配置还在，能卸载回退。 |

---

## 2. 设计审核

对照 Figma（HAUI）和 [设计规范 1.0](design-spec-1.0.md)。

- [ ] 同类设备共用同一张卡，不为每种设备另做一套外壳。
- [ ] 一台设备只出现在一张卡上，不把同一设备的信息拆到多张卡。
- [ ] 可选数据用卡片设置开关控制显隐，布局随模块伸缩。
- [ ] 只使用规范中的宽度档、圆角、间距、字体、颜色；不混用旧变量或临时缩小字号。
- [ ] 产品图与文字分层，不重叠。
- [ ] 主数值与单位之间有空格，例如 `35 %`、`22.5 °`。
- [ ] 至少覆盖这些状态的视觉：开 / 关、运行或充电中、不可用、未知；离线或关态有稳定处理。
- [ ] 卡片能适应 Home Assistant 里变化的栏宽，不能按设计稿里的固定像素死撑；变窄后不溢出、不重叠。

---

## 3. 配置审核

- [ ] 已注册，可在 Lovelace「添加卡片」中搜索到。
- [ ] 有可视化编辑器（HA 内用 `ha-form` 和实体选择器，标签中文）。
- [ ] 编辑器与 YAML 来回修改后，配置一致，刷新后仍在。
- [ ] 字段使用蛇形命名，与现有卡片风格一致（如 `show_toggle`）。
- [ ] 已有配置升级后仍可用；改字段必须兼容旧 YAML，或提供迁移说明。
- [ ] 点击信息区打开该实体的「更多信息」；开关、滑条、模式等控件自行处理点击，不误开更多信息。

---

## 4. 行为审核

- [ ] 绑定真实实体后，显示的名称、状态、数值正确。
- [ ] 写入操作调用正确的服务（开、关、调节等）。
- [ ] 实体为 `unavailable` 或 `unknown` 时，禁用写入，并显示「不可用」或「未知」。
- [ ] 服务调用失败时，卡片上留一句短错误，不能悄悄失败。
- [ ] 配错实体域、实体被删除、图片缺失时，卡片不白屏、不拖垮整个视图。
- [ ] 不修改 `configuration.yaml`，不改变 HA 侧边栏、顶栏和菜单。

---

## 5. 怎么测试

按下面四层做。前两层不过，不进入实机。

### 5.1 设计验收

对照 HAUI 与规范 1.0，检查第 2 节全部条目。重点看：模块开关、字号与间距、图文是否重叠、不同数据密度下高度是否正常。

### 5.2 本地预览

用仓库本地预览查看多种配置组合。这只能看版式，不能代替真实实体测试。

### 5.3 逻辑检查

检查状态文案、单位格式、是否显示开关、会不会对错误实体发写入。有自动测试的，必须通过后再提审。

### 5.4 Home Assistant 实机

第一次只在单独的「VHA 试验」视图中测试，不要先替换正在使用的主仪表盘。

- [ ] 按 README，用 HACS 自定义仓库安装成功，资源路径正确。
- [ ] 能添加卡片、保存、刷新后配置还在。
- [ ] 用真实实体验证显示和操作。
- [ ] 验证不可用、删除实体、配错域。
- [ ] 在电脑浏览器和手机 App 上各看一遍，并试不同栏宽。
- [ ] 刷新或升级后，其他原生卡和现有视图不受影响。
- [ ] 可以卸载或去掉资源，仪表盘能恢复。

浅色主题是默认验收环境。深色主题是否支持，要单独说明；未声明支持则不作为本轮否决项，但不得在深色下彻底不可用（例如白字白底）。

---

## 6. 发布档位

### 卡片通过

可以合并该卡的实现。

条件：第 2、3、4 节全部勾选；第 5.1–5.3 已做；已知问题已记录，且没有会导致误操作或页面崩溃的问题。

### 试用版

可以安装到 Home Assistant 的试验视图。

条件：满足「卡片通过」；第 5.4 节在试验视图走通；安装与卸载方式写在 README；版本说明写清这是试用，以及测的是哪几张卡。

不要求九张卡都完成。可以只发布已经通过的那几张。

### 正式小版本

可以视为基本可用，并占用一个正式版本号。

条件：满足「试用版」；你已在真实设备上验收设计与操作；电脑和手机都过了；已知问题有清单，且没有明显误操作风险。

往正在使用的 Home Assistant 安装前，须由仓库负责人确认。
