# VHA 设计规范 1.0

本文档记录 VHA 插件第一批卡片已经确立的视觉语言，作为设计 1.0。之后的卡片应使用这套语言去组织信息，而不是复刻某张参考图的布局，也不是把内容硬塞进某一张现成卡片壳子里。

来源：Figma 文件 [HAUI](https://www.figma.com/design/IwGZXxoRz00glVJcDiTEEE/HAUI)，页面「01 · Card」，展示板「Showcase · First batch」。数值均从该文件中的变量、文字样式与组件实测得出。

## 1. 整体特征

- 浅色、柔软、产品感：浅灰或雾蓝底，大圆角，轻阴影，留白多，没有硬描边。
- 拉丁字母和数字使用 Geist Regular / Medium；中文使用 Noto Sans SC 的对应级别（`VHA/Caption CJK`、`VHA/Footnote CJK`）。不要混用文件中残留的 VMA / PFC 字体样式。
- 标题和主数值接近黑 `#111111`；说明为中灰 `#3A3A3C`；次要说明为 `#6B6C6F`；弱化说明为 `#8A8B8E`；成功状态为柔和绿 `#3E8F6A`。
- 开关、侧栏、滑杆、选项芯片等控件是白色胶囊或圆形。
- 产品图和文字分层摆放，不叠在同一区域。
- 主数值与单位之间有空格，例如 `35 %`、`22.5 °`、`70 %`。

## 2. 四种排版形式

这是排版语言，不是四种不可改的壳。新卡片按信息结构选型或组合，并沿用同一套圆角、字号、颜色、控件和留白。

### 2.1 大图设备卡

参考：`vha-device-card` Type=Humidifier，448×436。

横向结构：左侧主区域（大数值 + 说明、开关，下方大圆角产品图），右侧白色竖向动作栏（宽 64）。适合带产品形象、开关和少量快捷操作的设备。

内边距约 24（右侧因动作栏可为 20），主区间距 16。产品图圆角 28。

### 2.2 竖图控制卡

参考：`vha-device-card` Type=Light，220×448。

纵向结构：顶部满宽产品图（高 196，可带左右切换；顶部不再额外留白），中间居中标题（28），底部白色竖向滑杆。适合只有一个连续调节的设备，例如亮度、音量、电量。

底部内边距 20，区块间距 12。

### 2.3 大读数洞察卡

参考：`vha-sensor-card` Type=AirQuality（480×840，圆角 44）与 `vha-climate-card`（448×580，圆角 40）。

结构：标题 + 更多菜单；中间 96 号主数值和一句短说明；下面是图表或模式芯片；底部横滑杆。背景为很淡的渐变：空气质量为桃到黄到薄荷到蓝，制热偏暖，制冷偏冷。适合强调一个核心读数，并带模式或目标调节。

内边距约 28–32。

### 2.4 指标块卡与媒体卡

参考：`vha-sensor-card` Type=PowerUsage（220×372）与 `vha-media-card`（448×372）。

用电卡：标题 + 两块白色指标磁贴（上标签、下数值）。媒体卡：标题行，左边圆形产品图和播放键，右边房间开关列表。底可以是浅雾蓝（`color/bg/card-muted`），也可以是淡渐变。

用电卡内边距 28 / 18 / 20 / 18，间距 14。媒体卡内边距 24 / 20 / 20 / 24。

## 3. 尺寸与间距

### 3.1 卡片宽度

三档：窄 220、标准 448、加宽英雄卡 480。

### 3.2 圆角（VHA Space）

| Token | 值 | 用途 |
| --- | --- | --- |
| radius/sm | 12 | 小元件 |
| radius/md | 16 | |
| radius/lg | 20 | |
| radius/xl | 24 | 芯片、房间行 |
| radius/2xl | 28 | 内部产品图、指标磁贴 |
| radius/3xl | 32 | |
| radius/card | 40 | 常规卡片 |
| radius/card-lg | 44 | 更高的英雄卡（如空气质量） |
| radius/full | 999 | 开关、滑杆轨道、动作栏、竖滑杆 |

### 3.3 间距阶梯（只使用这些值）

2、4、8、12、16、20、24、28、32、40。对应 `space/2` 到 `space/40`。

内边距大约 24 到 32。顶部满出血图的卡片不再额外留顶边。

### 3.4 阴影（效果样式）

- `VHA/Shadow/Card`：下移 10，模糊 28，黑色 7%。用于卡片。
- `VHA/Shadow/Soft`：下移 4，模糊 12，黑色 5%。
- `VHA/Shadow/Thumb`：下移 2，模糊 4，黑色 16%。用于滑杆圆钮。

## 4. 字体

文字样式均以 `VHA/` 为前缀。拉丁/数字为 Geist，中文对应级别为 Noto Sans SC。

| 样式 | 字号 / 行高 | 字重 | 字距 | 用途 |
| --- | --- | --- | --- | --- |
| VHA/Hero Number | 96 / 104 | Medium | -1.5 px | 洞察卡主数值 |
| VHA/Value Number | 44 / 52 | Medium | -0.5 px | 设备卡大数值 |
| VHA/Title | 32 / 38 | Regular | -0.4 px | 宽卡标题 |
| VHA/Title Center | 28 / 34 | Regular | -0.3 px | 窄卡居中标题 |
| VHA/Caption | 20 / 26 | Regular | -0.2 px | 说明 |
| VHA/Tagline | 20 / 26 | Regular | -0.2 px | 短标语 |
| VHA/Chip | 18 / 22 | Regular | -0.2 px | 选项芯片 |
| VHA/Body | 16 / 21 | Regular | -0.1 px | 正文、滑杆标签 |
| VHA/Metric Value | 16 / 20 | Regular | -0.1 px | 指标数值 |
| VHA/Footnote | 13 / 16 | Regular | 0 | 注释、滑杆旁百分比 |
| VHA/Caption CJK | 20 / 26 | Regular（Noto Sans SC） | -0.2 px | 中文说明 |
| VHA/Footnote CJK | 13 / 16 | Regular（Noto Sans SC） | 0 | 中文注释 |

不要为了塞进标题而临时缩小字号；应调整布局、换行或层级。

## 5. 颜色

使用集合 `VHA Primitives` 与 `VHA Color`（Light）。不要使用文件中的 VMA、PFC 旧变量。

### 5.1 背景与表面

| color/bg/card | `#F0EFF2` | 常规卡片底 |
| color/bg/card-muted | `#E3E9EE` | 雾蓝卡片底（如媒体卡） |
| color/bg/surface | `#FFFFFF` | 控件、磁贴、芯片 |
| color/bg/tile | `#F7F8FA` | 浅磁贴 |

| color/bg/rail | `#FFFFFF` | 动作栏 |
| color/bg/switch-off | `#C8C8C8` | 开关关 |
| color/bg/switch-on | `#5C574E` | 开关开（暖灰，不是系统蓝） |
| color/bg/thumb-on | `#3A372F` | 开状态旋钮 |

- 空气质量：`#FFEDC5` → `#F8F0C8` → `#F0F0D8` → `#E7F1EE` → `#D8EBFF`

## 6. 共用控件

- `vha-switch`：51×31，全圆，内边距 2，旋钮 27。
- `vha-chip`：内边距 14 / 18，圆角 24，字号 18。默认与选中都应可辨识；1.0 中选中态对比仍偏弱，后续应加强，不要再做几乎同色的白底选中。
- `vha-icon-button`：Ghost 36，Circle 44；图标约 22。
- `vha-overflow`：32×32 点击区域，省略号图标 22。
- `vha-action-rail`：宽 64，全圆白底，内边距 18 / 8，图标间距 22。
- `vha-room-row`：高约 47，圆角 24，内边距 8 / 8 / 8 / 16，标签 + 开关。
- `vha-metric-tile`：白底，圆角 28，内边距 18 / 12，间距 8，上标签下数值。
- `vha-slider-horizontal`：轨道高 4、全圆；圆钮 16；右侧注释字号 13。百分比写法应与主数值一样带空格（`45 %`），1.0 组件里仍有 `45%` 的不统一，后续改正。
- `vha-slider-vertical`：宽 80，全圆白底，内边距 22 / 8 / 18 / 8，顶部圆钮 44，底部注释 13。

## 7. 已知的 1.0 不严谨处

记录下来，作为后续清理项，不在本文档中视为正确规范：

- 横滑杆百分比 `45%` 与主数值 `35 %` 空格不统一。
- 选中芯片几乎仍是白底，对比偏弱。
- 用电卡下方留白偏多。
- 同一 Figma 文件中仍残留 VMA、PFC 变量与文字样式，VHA 卡片不得混用。

## 8. 使用原则

1. 先看这张卡要呈现什么信息，再从四种形式里选型或组合，而不是先选一张旧卡再填内容。
2. 只使用本文档中的宽度档、圆角、间距阶梯、字体样式和 VHA 颜色 token。
3. 产品图与文字分层，避免重叠。
4. 需要展示可选数据时，用同一张卡的模块显隐来适配，而不是为每种设备再做一套完全不同的外壳。

## 9. 电子设备卡的产品要求（与 1.0 同时确立）

电脑、手机、平板、笔记本等电子设备使用**同一张卡片**，一台设备只出现一张卡，不为每一种设备再做一套外壳。

卡片通过设置开关来选择显示哪些数据，例如（按设备实际可用项出现在编辑器中）：

- 产品图
- 电源开关
- 开机时长 / 电源状态
- 电池电量与充电状态
- 网络（Wi-Fi 名称或未连接）
- 位置（如在家）
- 温度（如显卡温度）
- 内存占用
- CPU 占用
- GPU 占用

布局随模块显隐伸缩，保持第 2–6 节的视觉语言。不要把这些信息拆到多张卡上，也不要为了塞数据而缩小字号或让文字与图片重叠。
